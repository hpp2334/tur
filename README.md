# tur

[tur](https://github.com/hpp2334/tur) (tiny ui reactive) is a UI engine that can be embedded in your application. It uses a [Flutter](https://flutter.dev)-like API at its core and a [SolidJS](https://www.solidjs.com)-style component model. Inspired by [Flutter](https://flutter.dev), [SolidJS](https://www.solidjs.com), and [GPUI](https://www.gpui.rs). Based on [vello-hybrid](https://github.com/linebender/vello) and [Boa](https://github.com/boa-dev/boa).

> **Still in early development — API and design may change frequently.**
